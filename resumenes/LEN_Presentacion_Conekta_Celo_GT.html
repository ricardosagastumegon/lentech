LENSeguridad
Modelo de confianza

Seguridad en cada capa

🔐

Webhooks — HMAC-SHA256

Conekta y Banrural firman cada request. LEN verifica la firma antes de procesar. Comparación timing-safe para evitar ataques de tiempo.

🪙

Contratos Celo — Roles separados

Solo MINTER_ROLE puede mintear. Solo BURNER_ROLE puede quemar. Solo la treasury wallet de LEN tiene ambos roles. Pausable en emergencias.

🎫

JWT — HS256 firmado

Tokens firmados con secreto de 256 bits. Expiración de 24h. Verificación criptográfica en cada request de usuario. No hay decode sin verificar.

🔄

Idempotencia — Firestore

Cada evento webhook tiene ID único registrado en Firestore. Si Conekta o Banrural reenvían el webhook, LEN no mintea dos veces.

📊

Límites AML / UIF

$50,000 MXN máximo por transacción. $200,000 MXN diarios por usuario. Umbral regulatorio México (UIF). Verificación automática pre-ejecución.

🗄️

Firestore — Admin SDK

API routes usan Firebase Admin SDK con service account. Bypasa security rules. El cliente (navegador) tiene acceso cero a colecciones de producción.
